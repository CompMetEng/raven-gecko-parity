# Security policy

## Supported versions

Security fixes target the current `main`/`develop` branch and the latest release. Older
releases are not patched.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Instead, report it privately
through [GitHub's security advisories](https://github.com/{{FULL_REPO}}/security/advisories/new)
for this repository. Include enough detail to reproduce it; expect an initial response within
a few business days.
